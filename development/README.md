Comandos:

Sincronizar el archivo de `prisma/schema.prisma` con la base de datos, desde la base de datos.

```bash
npx prisma db pull
```

Sincronizar el archivo de `prisma/schema.prisma` con la base de datos, desde el esquema hacia la basa de datos.

```bash
npx prisma db push
```

Insertar Datos

```bash
ts-node main.ts
```
